## How I work

- **AI proposes, rules decide:** where accuracy matters, I let AI draft and suggest, and keep a deterministic system responsible for the final result.
- **Test with realistic data early:** if real data can't be used, I build realistic stand-ins with known right answers before the feature gets far.
- **Write down open questions and decisions:** I keep a running list of what's unresolved and what was decided, so work can pause and restart without being redone.
- **Measure the outcome, not a stand-in for it:** a green dashboard only matters if it tracks the thing users care about.
